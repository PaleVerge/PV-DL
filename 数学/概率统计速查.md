# 概率统计速查(机器学习够用版)

> 定位:面向 ML/DL 的**够用**速查,不追求刷题。每个主题一页纸:公式 + 直觉。
>
> 配套学习:可汗学院「Probability and statistics」系列视频(2 倍速,~3 天)+ 吴恩达课程 week1 的概率部分。

## 1. 随机变量与概率

- **随机变量**:把随机试验结果映射为数值。分**离散**(取值可数,如掷骰子)与**连续**(取值连续,如身高)。
- **概率公理**:$P(\Omega)=1$、$0 \le P(A) \le 1$、互斥事件可加。
- 连续随机变量用**概率密度函数** $f(x)$ 描述,$P(a \le X \le b)=\int_a^b f(x)\,dx$;单点概率为 0,所以连续情形只谈区间概率。

## 2. 条件概率与贝叶斯定理 ⭐

- **条件概率**:$P(A \mid B)=\dfrac{P(A \cap B)}{P(B)}$,即"已知 B 发生,再看 A 的概率"。
- **全概率公式**:$P(B)=\sum_i P(B \mid A_i)P(A_i)$(把样本空间按 $A_i$ 切分,加权求和)。
- **贝叶斯定理**(核心直觉:先验 → 后验):

$$
P(A \mid B)=\frac{P(B \mid A)\,P(A)}{P(B)}
$$

- **直觉**:$P(A)$ 是看到数据前的**先验**;看到数据 $B$ 后,用**似然** $P(B \mid A)$ 更新为**后验** $P(A \mid B)$。分类问题里"根据特征判断类别"就是算后验。
- **独立性**:$P(A \cap B)=P(A)P(B)$ 则 A、B 独立 → 朴素贝叶斯"朴素"在假设特征条件独立。

## 3. 期望与方差 ⭐

- **期望**(均值中心):离散 $E[X]=\sum x_i p(x_i)$,连续 $E[X]=\int x f(x)\,dx$。
- **线性性质**:$E[aX+b]=aE[X]+b$;但 $E[XY]=E[X]E[Y]$ 仅在独立时成立。
- **方差**(离散程度):$\mathrm{Var}[X]=E[(X-E[X])^2]=E[X^2]-(E[X])^2$。
- **标准差**:$\sigma=\sqrt{\mathrm{Var}[X]}$,与 X 同量纲,便于解释。
- **协方差 / 相关系数**:衡量两个变量同向变化程度,$\mathrm{Cov}(X,Y)=E[(X-\mu_X)(Y-\mu_Y)]$。ML 中特征相关性、PCA 都依赖它。

## 4. 常见分布

| 分布 | 概率/密度 | 期望 | 方差 | 用途 |
|---|---|---|---|---|
| 伯努利 | $P(X=1)=p$ | $p$ | $p(1-p)$ | 二分类标签 |
| 二项 | $P(k)=\binom{n}{k}p^k(1-p)^{n-k}$ | $np$ | $np(1-p)$ | n 次独立试验成功次数 |
| 均匀 | $f(x)=\frac{1}{b-a}$ | $\frac{a+b}{2}$ | $\frac{(b-a)^2}{12}$ | 随机初始化、采样 |
| 正态/高斯 | $f(x)=\frac{1}{\sqrt{2\pi}\sigma}e^{-\frac{(x-\mu)^2}{2\sigma^2}}$ | $\mu$ | $\sigma^2$ | **最常用**:噪声、初始化、参数假设 |

- **正态的 68-95-99.7 法则**:落在 $\mu\pm\sigma$、$\pm2\sigma$、$\pm3\sigma$ 内的概率约 68%、95%、99.7%。
- **中心极限定理**:大量独立同分布随机变量的均值近似正态——这是"噪声假设高斯"的理论底气。

## 5. 最大似然估计 MLE ⭐

- **似然函数**:给定观测数据 $x_1,\dots,x_n$ 和带参数 $\theta$ 的分布,$L(\theta)=\prod_{i=1}^n p(x_i;\theta)$——"这批数据出现的概率"。
- **做法**:求使 $L(\theta)$ 最大的 $\theta$。取对数不改变最优点,且把连乘变连加:

$$
\hat\theta=\arg\max_\theta \sum_{i=1}^n \log p(x_i;\theta)
$$

- **直觉**:选一个参数,让"看到眼前这批数据"这件事最有可能。
- **例子**:高斯分布下做 MLE,解出来 $\hat\mu=$ 样本均值、$\hat\sigma^2=$ 样本方差;线性回归最小二乘等价于"高斯噪声假设下的 MLE"。

## 6. 与 ML / DL 的挂钩(学完回头再看)

- **交叉熵损失 = 负对数似然**:分类模型输出的概率分布与真实标签的交叉熵,就是最大化似然的等价形式。
- **均方误差 = 高斯噪声假设下的 MLE**:线性回归里最小化 MSE 与最大化高斯似然一致。
- **贝叶斯先验 → 正则化**:给参数加高斯先验,等价于 L2 正则(权重衰减);拉普拉斯先验 → L1。
- **期望/方差贯穿全程**:损失是经验期望、过拟合与方差-偏差分解、批量梯度估计都建立在这些概念上。
